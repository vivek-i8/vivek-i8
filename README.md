## `06 / CURRENT DIRECTION`

### AI-native systems

I'm especially interested in what happens when AI becomes an actual component of software:

```text
        MODEL
          │
          ↓
      RETRIEVAL
          │
          ↓
       REASONING
          │
          ↓
        TOOLS
          │
          ↓
        STATE
          │
          ↓
       POLICIES
          │
          ↓
       EXECUTION
```

The interesting problem isn't just **“can the model do it?”**

It's:

**“can we build a system around it that is useful, observable, controllable, and reliable?”**
